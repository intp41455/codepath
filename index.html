怎样使用循码

从“零号训练营”第一课开始。不会打字也没关系：先认识鼠标、窗口和文件夹，再玩不写代码的小游戏，最后才进入第一行 Python。

  • 卡住时：点“卡住了，点这里自救”。先只解决眼前一个符号或动作，不要求一次记住。
  • 闯关乐园：答错会扣爱心并解释原因；爱心归零可立即重来。星星与 XP 只是练习记录。
  • Python / SQL：首次运行需要联网下载浏览器运行环境。代码在当前浏览器执行；SQL 使用每次重建的练习数据库。
  • JavaScript / TypeScript：隔离执行 JavaScript；TypeScript 先做 strict 编译检查。DOM 与真实网络项目在本机实践。
  • Linux / Java / 框架：按课内步骤在本机真实运行，网页提供知识测验和人工验收清单，不会假装已经编译或部署。
  • Agent：基础课使用明确标注的模拟模型，先练习流程、工具和边界；真实模型接入在项目中完成，可能产生服务费用。
  • 学习记录：仅保存在当前浏览器，清理网站数据会丢失。定期点击底部“备份学习进度”。

框架安装时使用课内官方入口选择兼容版本。
