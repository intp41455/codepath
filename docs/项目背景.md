# 项目背景

## 它是什么

「循码 Codepath」是一个面向零基础学习者的中文编程实践课堂。它不是视频课程，也不是文档站，而是一个**可在浏览器里直接动手**的学习系统：

- 打开网页，从 Python 第一行 `print` 开始；
- 每个小节都是「讲解 → 动手 → 运行检查 → 复盘」的闭环；
- 练习在浏览器里**真实执行**（Python / SQL / JS / TS），用真实断言判定通过与否；
- 学到后段进入综合项目，最终用两套「拿证据说话」的毕业验收收尾。

一句话概括：**把「看懂了」逼成「我会了」，并且每一步都有可验证的证据。**

## 为什么做

编程学习最常见的两个劝退点：

1. **只看不练**——教程里每行都懂，自己一写就错，缺少即时反馈。
2. **环境门槛**——装语言、配依赖、开编译器，第一步就流失一半人。

循码针对这两点设计：

- 用浏览器内的 Web Worker / Pyodide / SQLite，把「真实运行」搬进网页，**无需安装任何东西**就能写出并跑通 Python、SQL、JS、TS。
- 练习不是「照着抄」，而是**带断言**：写对才过，没写会被拒，写错业务逻辑也会被拒——把「看起来对」和「真的对」区分开。
- 课程规模刻意做小（每节 5–10 分钟），强调「一点点，也算向前」，用每日挑战 + 首次完成 XP 维持节奏。

## 课程与能力边界（诚实声明）

这一点写进课程本身，也是项目价值观的一部分：

| 说法 | 循码的态度 |
| --- | --- |
| 「完成打卡 = 精通」 | ❌ 不承诺。学时只是阅读与首次练习的估计，熟练靠反复练习、独立项目和真实问题。 |
| 「网站帮你审了整个仓库」 | ❌ 审核中心只跑单文件 JS/TS/Python + 业务断言 + 部分静态提示，**不会自动审查任意仓库**。 |
| 「自评分是能力认证」 | ❌ 毕业自评分只检查记录完整度，不是第三方能力认证。 |
| 「真实模型已接入」 | ❌ 网站没有接入任何聊天模型；Agent 练习使用确定性模拟，真实模型集成留到本机项目阶段。 |
| 「静态扫描 = 安全审计」 | ❌ 是启发式规则，存在误报漏报，不能替代完整漏洞审计或生产安全保证。 |

> 这些边界同时出现在 README、课程页面与 `dist/test-report.html` 里，避免「网站很厉害」的误解。

## 关键设计选择

1. **纯静态、零构建**：没有框架、没有 npm 依赖、没有后端。整站就是一个 `dist/` 目录，`git clone` 后本地起 HTTP 服务即可运行。TypeScript 编译器（5.9.3）作为静态资源随仓库分发，保证「类型检查」也能离线可用。
2. **隔离执行**：学习者代码跑在「不透明源 iframe + 一次性 Worker」里（`sandbox.js`），与站点本身不同源，拿不到站点存储和 DOM；Python/SQL 用 Pyodide，JS/TS 用内联编译器。运行 5 秒、加载 90 秒双超时，无限循环会被自动停止。
3. **共享纯逻辑**：XP 计算、每日奖励去重、状态归一化、备份合并、静态风险扫描全部抽到 `learning-core.js`，**同一份逻辑既被页面使用、也被回归测试调用**，保证「页面行为 = 测试行为」。
4. **可复现测试**：仓库自带 Node 回归（60 项）+ Python/SQLite 参考实现（51 项）+ 可下载的 `codepath-tests.zip`。改课程、改逻辑后，跑一遍测试就知道有没有破坏行为。
5. **数据可迁移**：学习记录存浏览器 `localStorage`，键为 `codepath-learning-v1`，提供 JSON 导出 / 导入，跨浏览器迁移不丢笔记与进度。

## 目标用户

- 完全零基础、想系统入门编程、又不想被环境劝退的学习者；
- 已经会一点、想用「断言 + 证据」把自己逼到「真的会」的进阶者；
- 想系统补 Linux / 前端 / 智能体 / 源码阅读 / 复杂项目工程能力的工程师。
