# 第一部分 · 循码 Codepath

## 1.1 一句话是什么

**一个纯网页的中文编程课堂：打开浏览器就能写并运行真的 Python / SQL / JavaScript / TypeScript，不用装任何开发环境。**

| 项目 | 内容 |
|---|---|
| 站点 | codepath-academy.pages.dev |
| 源码 | github.com/intp41455/codepath（MIT 协议） |
| 面向 | 零基础 / 自学转行 / 想补基础的人 |
| 费用 | 全免费 |
| 技术形态 | 纯静态站点，无后端服务器 |

## 1.2 它解决的三个具体问题

1. **环境劝退**：多数教程第一步是"装 Python、配虚拟环境、装依赖"，很多人卡死在这一步。循码把这一步整个删掉——打开网页就能写。
2. **"看着都懂，一写就错"**：练习不比对输出，而是跑**真实断言**，能区分你到底是"没写""写错了"还是"业务逻辑错了"。
3. **不知道自己学到哪**：有学习路径、学习记录、每日挑战，进度可跨设备同步。

## 1.3 主界面八大板块（左侧导航栏，从上到下）

| 图标 | 板块 | 做什么用 |
|---|---|---|
| ⌂ | **今日学习** | 每天打开的第一屏，给当天的学习卡片（"今天学会…"）和入口 |
| ⌘ | **学习工作台** | 正在学的课程集中在这里，继续上次进度 |
| ◇ | **学习路径** | 全部课程体系，按路径分类浏览和进入 |
| ★ | **闯关乐园** | 6 个不写代码（或极少代码）的闯关小游戏 |
| ▧ | **实战项目** | 综合项目，把学过的知识点串成一个能跑的东西 |
| ✓ | **审核与测试** | 对代码做检查与自测，输出测试报告 |
| ▤ | **我的笔记** | 学习过程中的笔记与收藏（书签/归档） |
| ◷ | **学习记录** | 历史学习轨迹、完成情况回顾 |

底部固定入口：**隐私 · 协议 · 关于**（分别是隐私说明、用户协议、站点介绍页）。

## 1.4 课程体系（真实结构）

循码的课程不是"一篇文章+一段视频"，每节课是固定四段结构：

```
生活比喻 → 核心直觉 → 代码实操 → 检查点自动判定
```

**课程全景**（站内共 30 条学习路径 · 232 节，界面左下角可见「已完成 0 / 232 个小节」进度）：

| 模块 | 覆盖内容 |
|---|---|
| **零号训练营 · 先会用电脑** | 从认识鼠标、键盘、窗口、文件开始，每节只引入少量新词，不需要任何基础 |
| **编程思维 · 不写代码先会想** | 拆解问题的思维方式，先想清楚再动手 |
| **Python 慢速起步 / 基础与实战** | "一次只学一件事"的入门节奏，再到基础实战 |
| **语言与基础** | Python（26 节）· SQL · 数据结构 |
| **JavaScript · 网页开始行动** | 让网页真正动起来 |
| **TypeScript · 为代码建立约定** | 类型系统入门 |
| **Linux · 从终端到服务排障** | 终端、权限、进程、网络、日志与部署 |
| **读源码进阶**（20 节） | 陌生仓库先看什么 / 读目录 / 找入口 / 复现运行 |
| **AI 应用**（16 节） | 模型调用 / 结构化输出 / 工具调用 / Agent / 多智能体 |
| **智能体系统 · 架构与协作** | 多智能体系统的设计思路 |

> 说明：分模块的"节数"为源码统计值；对外引用总量时用「30 条学习路径 · 232 节」（站内显示口径）。

**课程右侧三栏布局**（这是循码最有辨识度的界面）：
- 左：知识讲解
- 中：任务清单（这节课要做的几步）
- 右：代码编辑区 + 运行按钮

## 1.5 闯关乐园：6 个小游戏

不写代码也能玩，用来建立"编程直觉"，零基础最先接触的就是这些：

| # | 游戏名 | 练什么 |
|---|---|---|
| 1 | 电脑探险岛 | 认识电脑的基本组成与概念 |
| 2 | 指令迷宫 | 理解"指令按顺序执行" |
| 3 | Python 萌芽塔 | Python 语法入门直觉 |
| 4 | Bug 捕虫队 | 认识错误、学会看报错 |
| 5 | AI 安全守门员 | AI 应用的安全边界意识 |
| 6 | 陌生项目侦察局 | 面对陌生项目先看什么 |

> 这 6 个游戏是**小红书/短视频最好用的素材**——它们不吓人、有画面、有反馈，适合给"好奇但怕难"的人看。

## 1.6 每日挑战

- 数量：**14 道**（源码 `DAILY_CHALLENGES` 实核）
- 形式：每天一道微题，含算法小题和判断题（例如"这个 Agent 会停下来吗？""工具输出能指挥系统吗？"）
- 用途：养成每天打开的习惯，也适合碎片时间

## 1.7 代码是真的在跑，不是模拟

这是循码最硬的一点，也是宣传时最该讲清楚的一点：

| 语言 | 怎么跑的 |
|---|---|
| **Python** | Pyodide（wasm 版 CPython），**自托管在站点内**，没走公共 CDN |
| **SQL** | 每道题**重建一个 SQLite 练习库**，随便改不怕搞坏，下次运行恢复初始数据 |
| **JavaScript** | 沙箱隔离执行 |
| **TypeScript** | 内嵌真实编译器（5.9.3），练习会做 strict 编译检查 |

**断言系统（三态判定）**——不是"输出对不对"二选一：

| 状态 | 含义 |
|---|---|
| 没写 | 检测到你还没动手 |
| 写错 | 写了，但行为不对（还会告诉你错在哪一类） |
| 写对 | 通过真实断言 |

举例：故意改坏一行代码再运行，系统会告诉你这次是"答案错了"还是"业务逻辑错了"。

**零基础到能读懂开源项目源码的交互式实战学院**：不止教你写代码，更教你"看懂别人的代码"和"掌控 AI 生成的代码"。

|---|---|

## 2.4 核心模块

```
1. 打开 codemaster-academy.pages.dev

4. 想练读源码 → 进「GitHub 拆解实验室」，做一次热修复挑战
5. 想练判错 → 进「代码掌控力实训」，看两个事故案例
```

# 第五部分 · 已知边界与短板（诚实区）

> 这一节**不要删**。主动认领短板是这两个站最重要的调性资产，也是技术社区不反感你的原因。

## 循码

1. **首次运行要联网下环境**：Python 走 Pyodide，第一次跑要下载运行环境（约 10MB），需要几秒。**弱网/地下场景会慢**——所以别承诺"地铁上随时跑代码"。
2. **没有社区功能**：目前是单人学习闭环，没有讨论区、没有答疑社区。
3. **部分 AI 模块是"配置阅读"**：神经网络、RAG、LoRA 等模块里，能跑的先跑，**跑不了的会明确标注是配置/阅读**，不装样子。
4. **不登录只存本机**：换浏览器或清缓存会丢进度，想跨设备必须注册。

## CodeMaster

1. **事故复盘目前只有 2 个案例**，量不多。
2. **智能助教不填 Key 时**走本地引擎，回复偏模板化。
3. **它教的是"读和判"**，不是替你做项目——毕业项目得自己真做。
4. **首次跑 Python 同样需要联网下载运行环境**。

## 不要做的宣传口径

- ❌ "永久免费"（未来若要会员会很被动；统一说"目前全免费"）
- ❌ "离线可用 / 没网也能学"（不成立，首次要下载运行环境）
- ❌ "地铁上跑 Python"（弱网会翻车）
- ❌ 冒充能力认证（练习判定的是代码行为，不是能力评级）
